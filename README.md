# 飞牛监控 (fnMonitor)

fnOS 系统监控应用（FPK 原生应用）：实时监控 **系统资源 / Docker 容器 / 端口占用 / 硬盘 SMART**，支持**历史趋势**、**七套主题**（暗黑 / 灰白 / 蓝色 / 浅色清新 / 翡翠绿 / 暖黄 / 青色）。界面参照网络主流 NAS 监控面板的现代设计：浅色卡片网格、毛玻璃顶部导航、绿色强调色、卡片悬浮上浮动效、手机端底部 Tab 导航、各模块独立框架配色；总览一页聚合系统资源 / 硬盘 / 趋势 / 概览。v2.4.0 起集成网络主流硬件监控面板的核心能力：温度墙、实时功耗 RAPL、显卡实时监控、内存插槽可视化、硬盘 SATA 告警计数、一键健康报告、历史六维度趋势。v2.5.0 起：**界面整体重构**（布局全面自适应、卡片/导航现代化）、新增**音乐模块**与**天气模块**、所有监控数值统一 **2 位小数**。v2.5.1 修复：报告 / CSV / JSON **下载改为兼容应用中心 iframe**、资源趋势历史改为**每 60 秒持久化一条**（趋势默认显示最近 10 分钟，关闭重开历史保留）。v2.5.2：**时间·农历与天气独立成「🗓 时间与天气」面板**、本机 IP **过滤 Docker 网桥 172.x 与 IPv6**、版本信息移到**页面底部居中**、设置新增**一键初始化界面**与**天气自定义位置**。v2.5.3：**布局彻底重构**（所有功能模块整行横向铺开、内部卡片平铺填满整宽，消除空白）、网卡信息**同时显示 IPv4 与 IPv6**、天气位置**保存持久化**不再丢失、内置应用状态**实时刷新**（后台启停服务即时反映）、刷新按钮加**旋转反馈**、新增**数据保存目录**。v2.5.4：**主题扩充为 7 套**（新增翡翠绿 / 暖黄 / 青色）、**「时间与天气」默认置顶**、数据默认保存在安装数据目录下的 **localdata** 文件夹（可自行修改）、**各模块独立框架配色**（顶部彩条 + app/ui/config 提取）、**修复网络上下行趋势图 Y 轴数值被遮挡**（紧凑格式 + 绘图区左边距加大）。v2.6.2：**修复一键健康报告生成失败与历史趋势 CSV 导出为空**——报告聚合/渲染全面加固（异常值 NaN/Inf、异常表结构、缺失指标均不再报错，异常数值显示「--」，报告始终能生成）；CSV 导出逻辑加固（历史库无数据时返回带原因的说明文件，历史写入失败时输出详细日志便于定位）。v2.6.3：**修复「已安装应用端口」应用名显示为 ${common.display_name} 占位符**——部分第三方应用 manifest 的 display_name 是模板变量，自动从应用配置目录提取真实显示名，提取不到时回退显示应用 ID。

- 形态：飞牛 fnOS 原生 FPK 应用，装进应用中心，桌面一键打开
- 后端：Python 3 标准库（零第三方依赖）
- 前端：单文件 HTML + 原生 JS + 自绘 SVG 图表（零 CDN 依赖，完全离线可用）
- 存储：SQLite 本地持久化历史趋势（仅保存在本机，不外传）
- 界面设置（主题 / 当前模块 / 面板布局 / 隐藏状态）自动同步到服务器本地文件，换电脑或清浏览器缓存后自动恢复

## 打包

### 方式一：Windows 打包

1. 安装 [Python 3](https://www.python.org/downloads/)
2. 下载 fnpack Windows 版：[fnpack 官方文档](https://developer.fnnas.com/docs/cli/fnpack/)，解压后把 `fnpack-1.2.1-windows-amd64` 重命名为 `fnpack.exe` 并加入 PATH
3. 在本目录执行：
   ```powershell
   .\build.ps1
   ```
4. 生成 `fnmonitor_2.6.3_x86.fpk`（或类似文件名）

### 方式二：飞牛 OS 上直接打包

飞牛 OS 预置了 fnpack。把本工程目录传到飞牛（如通过 SMB / Web 文件管理），SSH 登录后执行：

```bash
cd /vol1/xxx/fnmonitor
bash build.sh
```

## 安装

1. 打开飞牛 OS → **应用中心** → 左下角 **手动安装**
2. 选择 `fnmonitor_2.6.3_x86.fpk`
3. 安装完成后桌面出现 **飞牛监控** 图标，点击即可打开面板
4. 也可直接浏览器访问 `http://<NAS_IP>:8777`

> 若提示"手动安装"入口关闭，请 SSH 执行：`appcenter-cli manual-install enable`

## 使用

- **概览**：CPU / 内存 / 存储 / 网络 / 温度 / 负载 / 运行时间实时卡片，5 秒自动刷新。**本机 IP 卡**按网卡分组显示 **IPv4 与 IPv6**（过滤 Docker 网桥 172.x / 链路本地 / 回环），自动换行不溢出。**温度卡片**以 CPU 温度为主值，副标题列出主板温度与各硬盘温度（硬盘温度优先读 sysfs，读不到时尝试 smartctl，均不可用则显示 --）
- **资源详情**：CPU 每核使用率、内存明细（已用/缓存/缓冲/可用）、磁盘各分区使用率与读/写速率
- **硬盘信息**：按物理硬盘逐块列出**品牌型号 / 物理容量 / 已用 / 使用率 / 温度 / SMART 健康 / 转速 / 通电时长 / 挂载点**（60 秒刷新）。容量读取的是硬盘物理大小（通过 lsblk），与"存储池逻辑容量"不同，更符合"我插了几块多大的盘"的直观认知；占用统计自对应挂载点。SMART 信息通过 `smartctl` 读取，需要系统已安装 smartmontools（多数 NAS 已预装；未装时健康列为 --）
- **界面导航**：顶部模块 Tab（🏠 总览 / 🐳 Docker · 端口 / ⚙️ 设置），点击切换；手机端自动切换为**底部固定导航栏**。当前所在模块自动记忆并同步服务器
- **卡片网格布局（现代仪表盘式）**：所有监控面板以**等高卡片网格**平铺显示（`auto-fit` 自适应列数），宽度不足自动换行；趋势 / Docker / 端口等宽面板独占整行；隐藏某面板后其余面板自动让位补位
- **总览仪表盘（现代首页风格单页）**：服务器状态卡片网格实时显示 CPU / 内存 / 存储 / 网络 / 温度 / 负载 / 运行时间 / 本机 IP（自动换行不溢出）；**「🗓 时间与天气」独立面板**；下方依次为资源使用详情（CPU 每核 / 内存明细 / 磁盘分区与 IO）、硬盘信息（逐盘 SMART）、硬件与传感器（处理器 / 主板 / BIOS / 显卡 / 网卡 / RAID / 阵列卡 + **温度分类** CPU / 芯片组 / 主板 / ACPI / 硬盘 / GPU + **电压** + **风扇控制**）、资源趋势折线图、进程 TOP 20
- **硬盘 SMART**：按物理硬盘逐块列出品牌型号 / 容量 / 使用率 / 温度 / **SMART 健康 / 转速 / 通电时长** / 挂载点（60 秒刷新）。SMART 通过 `smartctl` 读取（`-n standby` 不唤醒休眠盘），需系统安装 smartmontools
- **Docker · 端口**（同一页）：上方 **Docker 容器**（容器状态与资源占用，15 秒刷新；运行时长中文；每行 启动 / 重启 / 停止 按钮，操作前确认），下方 **端口占用**（已安装应用端口 / Docker 容器端口映射 / 系统监听端口 `ss -tlnp` 含进程名/PID，60 秒刷新）
- **资源趋势**：CPU / 内存 / 存储 / **网络上下行**折线图，右上角切换时间范围（**默认最近10分钟** / 1小时 / 6小时 / 24小时 / 7天）。趋势标题右侧显示各图表数据点数。**持久化历史 + 实时双通道**：后端历史库**默认每 60 秒采样一条并持久化到本机**（历史数据保存在应用数据目录下的 `localdata/monitor.db`，**关闭应用 / 刷新页面 / 重开都不会丢失**，打开页面直接显示历史曲线）；若最新历史点过旧，后端自动附加当前实时值；前端每 5 秒把最新实时值追加到曲线尾部。网络曲线为所有物理网卡上下行速率之和（自动排除 docker0/veth/br 等虚拟网卡），Y 轴自动换算 KB/MB/GB。所有数值统一保留 2 位小数
- **温度墙**（v2.4.0 新增）：总览页新增**温度墙面板**——顶部 hero 四数（CPU / 主板 / GPU / 全部测点最高），下方彩色测点卡片墙（绿 / 橙 / 红随温度与阈值变色，中文名 + 悬停显示原始传感器名），CPU / 芯片组 / 主板 / 内存 DIMM / PCH 等全部测点一览，10 秒刷新
- **实时功耗与显卡**（v2.4.0 新增）：总览页新增**⚡ 实时功耗与显卡面板**——CPU **实时功耗（RAPL）** 按 封装 / 核心 / 非核心 / 内存 分域显示（>40W 红、>20W 橙，需 Intel CPU 且内核挂载 powercap）；**显卡实时状态**显示每个 GPU 的温度 / 利用率进度条 / 显存占用 / 频率（NVIDIA nvidia-smi / AMD sysfs / Intel 核显自动识别），10 秒刷新
- **内存插槽**（v2.4.0 新增）：硬件面板下方新增**内存插槽可视化**——按插槽画方块，已插内存显示品牌 / 容量 / 频率 / 类型，空槽虚线显示，标注单双通道（读取 `dmidecode -t memory` SPD，300 秒刷新）
- **硬盘 SATA 告警计数**（v2.4.0 新增）：硬盘信息表新增**告警**列，显示重映射扇区 / 待重映射 / 无法纠正 / UDMA CRC 四个关键 SMART 计数（>0 标红显示具体数值，全 0 显示"无"），提前发现盘片老化与线材问题
- **一键健康报告**（v2.4.0 新增）：设置页新增**一键健康报告**——聚合最近 7 天各指标（平均 / 最大 / 最近 / 样本数）+ CPU / 内存 / 磁盘阈值异常告警，导出为自包含 HTML 报告文件
- **历史趋势八维**（v2.4.0 新增）：资源趋势新增 **功耗 / 温度（CPU+主板）/ 风扇平均转速 / 磁盘读写 IO** 四张折线图（原 CPU / 内存 / 存储 / 网络上下行），右上角切换时间范围（10分钟 / 1小时 / 6小时 / 24小时 / 7天）
- **时间·农历 / 天气（v2.5.2 独立面板）**：总览页新增**「🗓 时间与天气」独立面板**——**时间·农历卡**（实时时钟 + 农历日期 / 干支，纯本地计算不联网）与**天气卡**（温度 / 体感 / 湿度 / 风 / 天气图标，需联网，支持**设置里自定义位置**：填城市名如"徐州"或 纬度,经度，留空自动定位，失败自动隐藏）
- **Docker 容器**：容器状态与资源占用，15 秒刷新；显示**运行时长（中文）**；每行提供 **启动 / 重启 / 停止** 按钮（操作前会确认）。**计数卡**：运行中 / 已停止 / 镜像数
- **内置应用统计**：相册 / 影视 / 音乐 安装状态、应用数据占用、媒体条目数与占用（10 分钟更新，位于 Docker · 端口页）
- **进程 TOP**：CPU 占用前 20，30 秒刷新（位于总览页）
- **数据导出**（设置页）：
  - **历史趋势 CSV**：下拉选择范围（全部历史 / 最近 7 天 / 24 小时 / 6 小时 / 1 小时）后点"导出 CSV"，浏览器下载表格文件（含时间、CPU、内存、负载、存储、各分区与网卡速率等列，可用 Excel / WPS 打开）
  - **当前状态 JSON**：点"导出 JSON"下载全量快照（概览 / Docker / 进程 / 内置应用 / 系统信息）

## 配置

### 应用中心向导
在 飞牛 OS → 系统设置 → 应用 → 飞牛监控 → 设置 中可修改：

- **数据采集间隔**（5/10/15/30/60 秒，默认 10 秒）
- **历史数据保留时长**（1/3/7/30 天，默认 7 天）

修改后即时生效，无需重启。

### 网页设置面板
页面底部「⚙️ 设置」面板可修改：

- **服务监听端口**（写入 config.json，**重启应用后生效**；需在飞牛防火墙放行新端口）
- **数据采集间隔 / 历史保留天数**（即时生效）
- **界面设置同步**：把当前主题 / 面板布局 / 隐藏状态立即写入服务器本地文件（平时每次调整自动同步，无需手动点）

## 权限说明

本应用声明了 `run-as: root` 权限，原因：

- 需要读取 Docker 容器状态与资源占用（访问 docker.sock），并执行 **Docker 容器的启动 / 重启 / 停止**
- 需要读取 CPU 温度、systemd 服务状态、全部进程信息、飞牛内置应用的只读数据库
- 需要读取 /sys/class/hwmon 传感器并**写入 pwmN 控制风扇**（风扇控制仅在你点击滑块时触发）

应用自身不会修改系统文件；对容器的启停与风扇调速仅在你点击面板控件并确认后触发。监控数据只写在本应用自己的数据目录（`var`）中。

> **安全提示**：Docker 启停与风扇控制接口无身份验证（仅限面板按钮调用）。请仅在可信局域网内使用，**不要**将 8777 端口直接暴露到公网；如确需外网访问，务必经由带登录认证的反向代理（如 Nginx + Basic Auth）。

## 可选依赖

以下系统工具可提升监控深度，未安装时对应功能自动降级显示 `--`（不影响其他功能）：

- `smartmontools`（smartctl）——硬盘 SMART 健康 / 转速 / 通电时长 / 告警计数；多数飞牛系统已预装
- `lm-sensors`（sensors）——温度传感器分类 / 温度墙 / 电压 / 风扇转速；部分主板需加载对应内核驱动
- `storcli`——LSI MegaRAID 阵列卡详细信息（未安装时仅显示卡型号与类型判断）
- `dmidecode`——内存插槽 SPD 信息（品牌 / 容量 / 频率）；多数系统已预装
- `nvidia-smi` / amdgpu 内核驱动——独立显卡实时温度 / 利用率 / 显存（未装时对应 GPU 显示"未检测到"）

## 模块检测机制（后端保留，用于端口 / 应用统计）

**"是否已安装"** 通过四种方式判定（任一命中即视为已安装，未安装的默认不显示）：

1. **应用中心目录**：飞牛内置应用安装目录（`/usr/local/apps/@appcenter/trim.*`）是否存在
2. **systemd 单元**：`systemctl list-unit-files` 中是否存在对应服务
3. **可执行文件**：常见 PATH（`/usr/bin`、`/usr/sbin` 等）下是否存在对应二进制
4. **Docker 镜像**：本机是否已拉取对应容器镜像

**"运行状态"** 仅对已安装模块做三路检测（任一命中即视为运行中）：

1. **systemd 活动状态**：如 `smbd`、`docker`、`sshd`
2. **进程名**：如 `nmbd`、`aria2c`、`sshd`
3. **Docker 容器名**：如 `jellyfin`、`alist`、`movie`、`photo`

已内置 20+ 常见检测项。如需新增，编辑 `app/server.py` 中的 `MODULES` 列表后重新打包即可。

## 内置应用统计机制

"相册 / 影视 / 音乐"统计（每 10 分钟更新）基于飞牛内置应用的目录与数据库：

- 应用数据目录：`/usr/local/apps/@appdata/trim.photos`、`trim.media`、`trim.music`（含 `/vol*` 下位置探测）
- 媒体条目数：**只读打开**应用 SQLite 数据库（如相册 `db/photo.db`），自适应查找含文件路径与大小字段的表统计
- 未安装的应用显示"未安装"；数据库结构不兼容时媒体条目显示 `--`（应用数据占用仍正常显示）

## 常见问题

**Q: 面板显示"docker 命令不可用或无权限"**
A: 确认应用以 root 权限运行（本应用默认 root）。可在应用设置中查看运行状态；或 SSH 执行 `docker ps` 确认 Docker 正常。

**Q: 温度显示为空**
A: 部分平台传感器路径不同。程序会依次读取 `/sys/class/thermal` 与 `/sys/class/hwmon`，仍读不到时可能为虚拟机或硬件不支持。

**Q: 卸载后重新安装，历史数据还在吗**
A: 卸载向导选择"保留数据"则历史趋势保留；选择"删除所有数据"则清空。

**Q: 趋势图刚打开是空白 / 没有历史曲线**
A: 趋势采用**持久化历史 + 实时双通道**：后端默认每 60 秒向本机历史库写一条数据（关闭应用 / 刷新 / 重开都不丢失），最新历史点过旧时后端自动附加当前实时值，前端每 5 秒也会把最新实时值画到曲线尾部。因此打开页面后 CPU / 内存 / 存储 / 网络各图**应立刻有历史曲线 + 1 个以上的实时点**并持续增长。若仍空白，请查看趋势标题右侧的点数标签（如"CPU 0点"）——若显示 0 点，请反馈该数字，并在飞牛上 SSH 执行 `cat /vol*/@appdata/fnmonitor/server.log` 查看后端日志；`/api/history/diag` 接口可返回数据库写入状态。

**Q: 端口被占用怎么办**
A: 在页面底部「⚙️ 设置」面板修改**服务监听端口**并保存，随后在 应用中心 → 飞牛监控 → 重启，即可用新端口访问（需在飞牛防火墙放行新端口）。若需彻底改固定端口，可修改 manifest 中 `service_port` 与 `app/ui/config`、`fnmonitor.sc` 三处后重新打包。

**Q: 首页天气卡不显示 / 显示"--"**
A: 天气模块需要飞牛能够访问外网（公网定位 ip-api.com + 天气 Open-Meteo）。若网络不可达、被墙或服务不可用，天气卡自动隐藏，**不影响其他任何监控功能**。天气数据每 30 分钟刷新一次，不消耗流量。若想固定城市，可在「⚙️ 设置」→「天气位置（自定义）」填写城市名（如 徐州）或 纬度,经度（如 34.26,117.18），保存后天气卡立即刷新。

## 数据与隐私

- 所有监控数据仅存储在飞牛本机应用数据目录（**默认 `…/localdata/monitor.db`**，即软件安装数据目录下的 localdata 文件夹）
- **自定义数据保存目录**（v2.5.3 / v2.5.4）：默认数据保存在软件安装数据目录下的 **localdata** 文件夹中；如需改到自己指定的文件夹，可在「⚙️ 设置」→「数据保存目录」填入飞牛存储空间的绝对路径（如 `/vol1/监控数据`，**请先自行在飞牛文件管理中创建该文件夹**），点保存后**在应用中心重启「飞牛监控」**生效；重启时会把已有的历史数据库 / 界面设置自动复制到新目录，之后所有数据（含资源趋势历史）都会持久化保存到该文件夹，不会因卸载 / 换机丢失。**留空则使用默认 localdata**
- 除 **天气模块** 外，其余功能均**不联网、不上传、无任何外部服务依赖**
- **天气模块**（可选）：仅当你在首页看到天气卡时才会发起外网请求——通过公网 IP 查询城市（ip-api.com，仅返回位置信息），再向 Open-Meteo 获取当前天气（免费无需 key）。**位置与天气数据只在飞牛本机与这两家服务之间传输，不会上传到任何第三方**；若网络不可达或服务不可用，天气卡自动隐藏，不影响其他任何功能。介意联网的用户可忽略该卡片（不会影响监控）。
