⚙️ 设置
服务监听端口
修改后需在 应用中心 → 飞牛监控 中「重启」应用生效；并需在飞牛防火墙放行新端口
数据采集间隔
监控刷新周期（秒，5-3600），值越小越实时但负载略高
历史数据采样间隔
历史趋势记录周期（秒，60-86400，默认 60）；值越小趋势越密
历史保留天数
超过保留期的历史数据会自动清理
界面设置同步
主题 / 面板布局 / 隐藏状态保存到服务器本地文件 ui.json，换电脑或清浏览器缓存后自动恢复。
当前保存位置：读取中…
数据实际保存在 NAS 服务器端上述文件中（浏览器里仅存显示缓存，换设备后仍以 NAS 数据为准）。保存位置由下方「数据保存目录」统一决定，修改目录并重启应用后，界面数据将保存到新位置（旧 ui.json 不会自动迁移，需要保留可在重启前手动拷贝）
字体大小
整体缩放页面文字与界面元素，立即生效；选择后自动保存到 NAS 服务器端的界面配置（ui.json），换设备 / 清浏览器缓存后仍生效。默认「标准（100%）」即 v2.8.4 及之前版本的原始字体大小，如界面显示偏大偏小可随时在此调回
界面管理（显示 / 隐藏恢复）
被隐藏的面板和小模块都会列在这里，点击名称即可单独恢复显示；也可以点击右侧按钮一次性全部恢复

关于 飞牛监控（fnMonitor）
v-- · 为飞牛 fnOS 打造的系统监控面板 · 纯本地运行 · 开源免费
实时监控 CPU / 内存 / 磁盘 / 网络 / 温度 / 功耗 / GPU，Docker 容器与端口占用，内置应用统计与历史趋势；所有数据（历史记录 / 界面设置 / 配置）均保存在 NAS 服务器端的程序数据目录中，与访问所用的电脑无关。
